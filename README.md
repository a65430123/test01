# 烈焰英雄傳

一款單一 HTML 檔的暗黑奇幻風即時打怪升級網頁遊戲，玩法參考經典網頁 MMORPG：點擊移動、自動戰鬥、自動掛機、打怪掉寶、裝備強化、任務鏈與 BOSS 挑戰。所有角色與場景都用 Canvas 程式繪製，不需要任何圖片素材。

## 遊玩方式

用瀏覽器直接開啟 `index.html` 即可（電腦與手機皆可）。

| 操作 | 按鍵 |
| --- | --- |
| 移動 | 滑鼠點擊地面、手指拖曳、WASD 或方向鍵 |
| 攻擊 | 點擊怪物（自動追擊並普攻） |
| 技能 | 1 / 2 / 3 |
| 紅藥 / 藍藥 | Q / E |
| 自動掛機 | Z |
| 背包與角色 | B |
| 屬性點與技能修煉 | C |
| 回城 | T |

## 內容

- **男女角色**：建立角色時可選擇男性或女性
- **三種職業**：劍客（近戰）、術士（遠程法術）、遊俠（弓箭），每個職業有 3 個技能，分別在 Lv1、Lv5、Lv12 解鎖
- **八張野外地圖**（Lv 1～60），每張都有首領：
  - 綠野森林（Lv 1-9）、幽暗洞窟（Lv 10-17，洞穴蛛后）、熔岩魔域（Lv 18-28，炎魔君主）
  - 冰封雪原（Lv 26-33，冰霜女王）、亡者墓地（Lv 34-41，死靈領主）
  - 沙漠遺跡（Lv 42-49，沙蟲之王）、龍之巢穴（Lv 50-60，遠古黑龍）
- **試煉之塔**：限時清光每層敵人，每 5 層有首領，紀錄最高層數
- **懸賞任務**：可重複接的討伐令，每完成 5 張額外送裝備
- **屬性點與技能修煉**：每升一級 3 點屬性點（力量、體質、敏捷、智力）；技能可花金幣升到 Lv10
- **寶藏哥布林**：野外隨機出現、會逃跑，擊倒掉落大量金幣與裝備
- **遠程敵人**：骷髏法師、冰霜女王、幼龍、黑龍會發射投射物
- 主線任務擴充為 15 段
- **村莊 NPC**：村長（主線）、懸賞官、試煉守衛、雜貨商（藥水、一鍵出售）、鐵匠（裝備強化 +1～+10）、傳送師
- **裝備系統**：5 個部位、5 種品質（普通、優秀、精良、史詩、傳說），提供一鍵換裝
- **自動掛機**：自動找怪、放技能、撿東西、喝藥
- **自動存檔**：進度存在瀏覽器的 localStorage

## 依裝備改變外觀

角色是程式繪製的分層造型（披風、頭髮、腿、軀幹、肩甲、頭盔、武器），每個部位依裝備的「階級 tier」（0 木/布 ～ 8 龍神）決定外觀：

- 武器：劍身長度、顏色、護手與刃光；法杖的寶石；弓的材質與裝飾
- 衣甲：主色、鑲邊、肩甲大小與披風；劍客顯示為板甲、術士為長袍、遊俠為皮甲
- 頭盔：頭帶、皮帽、鐵盔、羽飾盔、角盔、龍盔、王冠
- 鞋子：靴子顏色；戒指達史詩以上時腳下出現光環
- 武器品質達「精良」以上會發光

要新增或調整造型，修改 `index.html` 裡的 `ARMOR_LOOK`、`HELM_LOOK`、`BOOT_LOOK`、`WEAPON_LOOK`、`CLASS_LOOK` 表即可。

## 發布網頁版

修改 `index.html` 後執行 `python3 tools/build_artifact.py`，再發布產生的 `dist/artifact.html`。
