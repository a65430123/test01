# Q萌英雄傳

一款單一 HTML 檔的 Q 版即時打怪升級網頁遊戲，玩法參考經典網頁 MMORPG：點擊移動、自動戰鬥、自動掛機、打怪掉寶、裝備強化、任務鏈與 BOSS 挑戰。所有角色與場景都用 Canvas 程式繪製，不需要任何圖片素材。

## 遊玩方式

用瀏覽器直接開啟 `index.html` 即可（電腦與手機皆可）。

| 操作 | 按鍵 |
| --- | --- |
| 移動 | 滑鼠點擊地面、手指拖曳、WASD 或方向鍵 |
| 攻擊 | 點擊怪物（自動追擊並普攻） |
| 技能 | 1 / 2 / 3 |
| 紅藥 / 藍藥 | Q / E |
| 自動掛機 | Z |
| 背包與角色 | B |
| 回城 | T |

## 內容

- **三種職業**：劍客（近戰）、術士（遠程法術）、遊俠（弓箭），每個職業有 3 個技能，分別在 Lv1、Lv5、Lv12 解鎖
- **四張地圖**：晨曦村（安全區）、綠野森林、幽暗洞窟（菁英：洞穴蛛后）、熔岩魔域（BOSS：炎魔君主）
- **村莊 NPC**：村長（任務鏈）、雜貨商（藥水、一鍵出售）、鐵匠（裝備強化 +1～+10）、傳送師
- **裝備系統**：5 個部位、5 種品質（普通、優秀、精良、史詩、傳說），提供一鍵換裝
- **自動掛機**：自動找怪、放技能、撿東西、喝藥
- **自動存檔**：進度存在瀏覽器的 localStorage
